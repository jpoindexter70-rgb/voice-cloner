Storage & Privacy

This browser edition stores profiles and audio privately in this browser on this computer. It does not write to D: automatically. Clearing browser data can remove the library: export a private backup and save it on D:.
Child voice access is locked pending a verified guardian process. Permission records are locally documented, not independently identity verified. Use a private OS account and disk encryption for device-level protection.
Revoking consent blocks playback and new recordings. Deleting a profile removes its local folder permanently; exported files and external backups are outside the app's control.
